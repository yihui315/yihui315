## Script Usage Quick Reference

Run closeout validation:

```powershell
& .\Codex_L1_Governance\scripts\round-closeout-validator.ps1 -Json
```

Run artifact hygiene dry-run:

```powershell
& .\Codex_L1_Governance\scripts\governance-artifact-hygiene.ps1 -Json
```

Run artifact hygiene with explicit targets and threshold:

```powershell
& .\Codex_L1_Governance\scripts\governance-artifact-hygiene.ps1 `
  -TargetDirectories @("artifacts", "screenshots", "logs", "mcp") `
  -OlderThanDays 90 `
  -DryRun:$true
```

Run weekly governance health check:

```powershell
& .\Codex_L1_Governance\scripts\weekly-governance-health-check.ps1 -Json
```

## Blocked Protection Mechanisms

| Script | Blocked condition | Behavior |
| --- | --- | --- |
| `round-closeout-validator.ps1` | Required L1 files missing, decision JSON parse failure, or `.env*` files present under L1 | Exits blocked and does not approve round closeout |
| `governance-artifact-hygiene.ps1` | Target path outside L1 root or sensitive-shaped path such as `.env`, `secret`, `provider`, or `payment` | Exits blocked and writes plan-only evidence |
| `weekly-governance-health-check.ps1` | Closeout blocked, artifact hygiene blocked, secret-shape hits, or env-like files present | Exits blocked or conditional and writes a weekly health report |
| `human-evidence-intake-check.ps1` | `submitted_by` missing, rows incomplete, invalid `present`, `present=yes` without evidence path, or secret-shaped content | Exits blocked and writes intake report without changing evidence |

Both scripts are read-only for governance purposes. Neither script grants project execution, revenue, or production readiness.
